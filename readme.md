# 📚 Snap & Study — AI Vision Chatbot

Snap & Study is an AI-powered educational assistant that helps students understand study materials using text and images.

## ✨ Features

- 💬 Ask questions and receive AI-powered explanations.
- 📸 Upload images of handwritten notes, diagrams, and questions.
- 🧠 Maintain conversation context for follow-up questions.
- 📧 Email explanations to save them for later reference.
- 🎓 Learn complex topics through simple, student-friendly explanations.

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Gmail SMTP
